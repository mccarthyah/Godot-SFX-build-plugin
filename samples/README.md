# Sample library (CC0)

Curated set of 76 sounds from **[wyzowl/sfx-kit](https://github.com/wyzowl/sfx-kit)** —
320 original game sound effects, released under
[CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/).
The samples are public domain; attribution is not required, but credited here
with thanks. The additional selections broaden the library with cinematic
hits, digital glitches, notifications, typing, transformations, and more.

Use these as raw material in the SFX Generator: choose **Mode → Sample**,
select a recording, and alter it with pitch shift, looping, reversing, the
ADSR envelope, and the full effects chain. The dock scans this directory
recursively, so additional WAV files placed in `res://samples/` appear in the
sample list after Godot imports them and the dock is reloaded.
