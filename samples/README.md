# Sample library (CC0)

The complete set of **320 original game sound effects** from **[wyzowl/sfx-kit](https://github.com/wyzowl/sfx-kit)**,
released under [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/).
The samples are public domain; attribution is not required, but credited here
with thanks. The source license text is included as [`LICENSE-CC0.txt`](LICENSE-CC0.txt).

Use these as raw material in the SFX Generator: choose **Mode → Sample**,
select a recording, and alter it with pitch shift, looping, reversing, the
ADSR envelope, and the full effects chain. The dock scans this directory
recursively, so additional WAV or OGG files placed in `res://samples/` appear
in the sample list after Godot imports them and the dock is reloaded.

The 320 files in this original Wyzowl collection are 48 kHz, 16-bit PCM WAVs.
Additional CC0 effects and instrument samples, including OGG files, are listed
in [`community/README.md`](community/README.md). The full picker now contains
1,951 audio files across the Wyzowl and community collections.
