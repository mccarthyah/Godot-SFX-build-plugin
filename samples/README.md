# Sample library (CC0)

Curated subset of **[wyzowl/sfx-kit](https://github.com/wyzowl/sfx-kit)** —
320 original game sound effects, released under
[CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/)
(public domain — no attribution required, but credited here with thanks).

Use these as raw material in the SFX Generator: pick **Mode → Sample** in the
dock, choose a sample, then alter it with pitch shift, looping, reversing and
the full effects chain (filter, distortion, delay, reverb…).
